🚗 VEHICLE MANAGEMENT SYSTEM

📌 Project Description

The Vehicle Management System is a console-based application developed in Java using the BlueJ development environment. It enables efficient vehicle record management, maintenance tracking, service booking, and billing generation through a file-handling based storage system.


🚀 Features


🚘 Vehicle Management

Add new vehicle records,
View all registered vehicles,
Search vehicles by registration number,
Update vehicle information,
Delete vehicle records.


🛠️ Maintenance Management

Vehicle health and condition tracking,
Fuel efficiency analysis,
Fuel status monitoring,
Upcoming service schedule tracking,
Maintenance recommendations and advice.


📅 Service Management

Book vehicle services,
Schedule service date and time,
Select service type,
View service booking records.


💰 Billing System

Generate vehicle service bills,
Insurance cost calculation,
Repair cost calculation,
Service cost calculation,
GST calculation and total billing.


📁 Data Storage

File-based record management,
Persistent storage using Java File Handling.


🛠️ Technologies Used


Programming Language: Java

Concepts Used:

File Handling,
Classes and Objects,

Arrays and Strings,
Menu-Driven Programming.
